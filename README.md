#  Product Comparison Tool (jQuery)

A responsive, frontend-only product comparison tool built using **HTML5, CSS3, jQuery, and vanilla JavaScript**.  
Users can compare up to **three products side-by-side**, with visual highlighting of differences, persistent state, and a polished UI.

---

##  Tech Stack

- HTML5
- CSS3 
- JavaScript 
- jQuery
- No backend / No APIs (static data only)

---

## Setup Instructions

### Clone or Download the Project

1. Clone the repository
2. Open `index.html` in a browser

##  Features

- Product listing with images, pricing, and key specs
- Compare up to 3 products side-by-side
- Difference highlighting at cell level
- Responsive design (desktop & mobile)
- Light / Dark mode toggle
- Search and filter products
- Comparison state persisted using localStorage

##  Assumptions

- Product data is static and stored locally
- No backend or API integration is required
- Maximum of 3 products can be compared at once
- Images are local assets
